# ONZE LINE 數位名片素材

LINE Flex carousel 名片的圖片與訊息 JSON。

| 檔案 | 用途 |
|---|---|
| `line-hero-01~03.png` | 名片圖（1080 × 1400，Flex hero 用） |
| `small-1024/line-hero-01~03.jpg` | 小尺寸備用（790 × 1024） |
| `card-01~03.png` | 含按鈕的完整卡片（展示用） |
| `onze-card.txt` / `line-flex-carousel.json` | Flex Message 全文（含 `type: flex`），供 LINE 數位版名片工具作為樣板 |

圖片直連網址格式：`https://raw.githubusercontent.com/pchen122/onze-line-card/main/line-hero-01.png`
